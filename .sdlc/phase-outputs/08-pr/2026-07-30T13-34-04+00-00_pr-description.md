## Summary
This change adds an automated documentation-sync pipeline for the Flask Task Manager repository. It scans canonical project files, extracts structured technical facts in strict-fact mode, and writes a Markdown technical profile that can be used for future documentation publishing.

## Changes Made
| File | Change Type | Reason |
|---|---|---|
| src/doc_sync/repo_scanner.py | Added | Reads the canonical repository files used by the documentation pipeline |
| src/doc_sync/extractor.py | Added | Extracts structured facts and normalizes missing values as "Not Specified" |
| src/doc_sync/page_creator.py | Added | Formats extracted facts into a Markdown technical profile report |
| src/main.py | Updated | Adds CLI support for repository and output path overrides |
| tests/unit/test_doc_sync.py | Added | Covers repository fact collection, problem-spec generation, and report creation |
| tests/unit/test_extractor.py | Added | Verifies strict-fact extraction and missing-value handling |
| tests/unit/test_repo_scanner.py | Added | Verifies repository scan behavior and fallback handling |
| tests/integration/test_pipeline.py | Added | Verifies the end-to-end documentation pipeline output |

- Some values remain "Not Specified" when the repository does not expose them explicitly.
