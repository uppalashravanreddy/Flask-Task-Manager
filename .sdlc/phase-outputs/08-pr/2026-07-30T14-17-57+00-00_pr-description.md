# FLASK-001: Automated Documentation Sync

## Summary

This PR introduces an automated documentation sync pipeline (`src/doc_sync/`) that scans a Flask repository's canonical files, extracts structured facts, and generates a versioned Markdown technical profile intended for the Confluence Documentation space. The pipeline solves the problem of documentation falling out of sync with the codebase by providing a repeatable, CLI-driven workflow that can be integrated into CI. Two pre-existing bugs were also corrected: `SECRET_KEY` was hardcoded in `app.py` (now sourced from `os.environ`) and `requirements.txt` contained invalid package entries that prevented clean installs.

## Known Limitations

- `/delete=/<id>` route URL contains a literal `=` character (existing quirk in `routes.py`); deferred — not in scope for this PR.
- The `page_creator.py` output targets Confluence Markdown format but does not yet POST directly to the Confluence API; the generated file must be uploaded manually.
- Playwright E2E tests require a Playwright browser installation (`playwright install`); they are not executed in the unit-test CI job.
- `repo_scanner.py` reads exactly 6 hard-coded canonical files; dynamic file discovery is deferred to a future iteration.
